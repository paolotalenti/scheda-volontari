Manuale Utente — Scheda Volontari

Introduzione

Scheda Volontari è un'applicazione web per gestire le visite dei volontari agli assistiti. Permette di registrare le visite, gestire l'anagrafica di volontari e assistiti, generare report e scaricare i dati. I volontari accedono direttamente alla pagina di inserimento senza bisogno di login. Le funzioni amministrative (report, gestione anagrafica, backup) richiedono autenticazione.

1. Accesso amministratore

Vai su Login Amministratore, inserisci la password e clicca su "Login". Dopo il login vieni reindirizzato alla pagina Report Visite.

Per cambiare la password amministrativa vedi la sezione 6. Cambia Password.

2. Inserimento visita (per volontari)

I volontari non necessitano di login. Dalla pagina Inserisci Visita:

  1. Inserisci l'email del volontario. Se l'email è già registrata i campi anagrafici vengono nascosti automaticamente. Se è nuova, compila cognome e nome (obbligatori), telefono, competenze e disponibilità (facoltativi).
  2. Seleziona l'assistito dal menu.
  3. Scegli il livello di accoglienza: Buona, Media o Scarsa.
  4. Inserisci la data della visita (obbligatoria).
  5. Aggiungi eventuali necessità e considerazioni (facoltativi).
  6. Clicca su Inserisci.

3. Report Visite

Vai su Report Visite. All'apertura della pagina la data di inizio è impostata automaticamente al 1° del mese precedente: questo limita la visualizzazione alle visite recenti evitando di caricare tutto l'archivio. Puoi modificare liberamente entrambe le date o cancellarle per vedere tutte le visite.

  1. Usa il filtro Volontario per restringere i risultati a una persona specifica (lascia "Tutti" per vedere tutto).
  2. Modifica Data Inizio e/o Data Fine secondo le tue esigenze.
  3. Clicca su Filtra per aggiornare la tabella.
  4. Scarica i dati filtrati con Scarica PDF o Scarica CSV.
  5. Per eliminare le visite visualizzate, inserisci la password amministrativa e clicca su Pulisci Visite Filtrate.

Nota: i filtri attivi si applicano anche ai file scaricati e alla funzione di pulizia.

4. Gestione Volontari

Vai su Gestione Volontari. Trovi tre pulsanti in cima alla pagina:

  • Aggiungi Volontario: inserisci email (unica), cognome, nome (obbligatori), telefono, competenze, disponibilità (facoltativi).
  • Scarica CSV: scarica l'elenco completo dei volontari in formato CSV, ordinato per cognome. Il file si chiama volontari.csv e si apre direttamente con Excel.
  • Modifica / Elimina: disponibili per ogni riga della tabella. L'eliminazione non è possibile se il volontario ha visite associate.

5. Gestione Assistiti

Vai su Gestione Assistiti. Trovi tre pulsanti in cima alla pagina:

  • Aggiungi Assistito: inserisci nome sigla (unico) e città (obbligatori).
  • Scarica CSV: scarica l'elenco completo degli assistiti in formato CSV, ordinato per città. Il file si chiama assistiti.csv.
  • Modifica / Elimina: disponibili per ogni riga. L'eliminazione non è possibile se l'assistito ha visite associate.

6. Cambia Password

Dal Report Visite clicca su Cambia Password (in fondo alla pagina). Inserisci la password attuale, la nuova password e la conferma. La nuova password viene salvata nel database ed è attiva immediatamente, senza bisogno di modificare le impostazioni del server.

Nota: se dimentichi la password, contatta l'amministratore di sistema che potrà reimpostarla direttamente su Render.

7. Backup e Ripristino

  • Backup automatico: eseguito ogni giorno alle 02:00. I file sono salvati nella cartella backups/ e quelli più vecchi di 7 giorni vengono eliminati automaticamente.
  • Backup manuale: clicca su Esegui Backup per creare subito un file CSV con tutti i dati (visite, volontari, assistiti).
  • Ripristino: vai su Ripristina Backup, seleziona un file di backup, inserisci la password amministrativa e clicca su "Ripristina".

Attenzione: il ripristino sovrascrive tutti i dati presenti. Esegui sempre un backup manuale prima di ripristinare.

8. Risoluzione dei problemi

  • Email o nome sigla già esistenti: ogni email volontario e ogni nome sigla assistito deve essere unico. Cambia il valore e riprova.
  • Password errata: usa la password corrente. Se non la ricordi, contatta l'amministratore di sistema.
  • Caratteri accentati nel CSV: il file è codificato in UTF-8 con BOM per la compatibilità con Excel. Se i caratteri non appaiono correttamente, apri Excel, usa "Dati → Da testo/CSV" e scegli la codifica UTF-8.
  • Eliminazione non riuscita: un volontario o assistito con visite associate non può essere eliminato. Pulisci prima le visite correlate dal Report.
  • Backup automatici mancanti: se il server Render va in standby, il job notturno potrebbe non partire. Esegui backup manuali periodicamente.
  • Ripristino fallito: verifica che il file selezionato sia un backup valido generato da questa applicazione.
